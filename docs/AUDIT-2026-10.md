# SKAIHUB — Audit Oktober 2026 (Fase 1A)

> Tanggal: 2026-10-17 · Disusun oleh lead (Claude) dari 3 audit read-only: skema (database-reviewer), keamanan (security-reviewer), paket & rute (code-explorer).
> Keputusan D1…Dn **diambil oleh lead atas delegasi pemilik project** (PLAN A9.8) dan dapat direvisi pemilik kapan saja.

## Ringkasan

- **Isolasi tenant umumnya rapi**: semua controller `Akademi/*` men-scope `akademi_id`, ID di body divalidasi `Rule::exists(...)->where('akademi_id')`. Satu pengecualian: `sport_ranks` global (F1).
- **Masalah terbesar ada di siklus hidup token dan eskalasi role** di dalam akademi (F2–F5) — wajib beres sebelum dijual.
- **Skema**: mayoritas perbedaan dengan SCHEMA.md hanya penamaan/desain yang lebih baik di kode → **dokumen yang disesuaikan**. Yang benar-benar kurang untuk MVP: status absensi `sick`, `spp_payments.akademi_id`, riwayat sabuk, prestasi internal, dan index.
- **Paket**: harga & limit konsisten di semua tempat. Kuota siswa belum ditegakkan (sedang dikerjakan, L1-A/1.7). Entitlement landing page hanya ditegakkan di endpoint publik, tidak di endpoint kelola.
- **Rute frontend**: subdomain `admin.<domain>` kemungkinan rusak (rewrite proxy ke `/admin/*` bertabrakan dengan stub redirect legacy).
- **Baseline test**: 5/43 test backend gagal di `main` sebelum audit (L1-A/1.0).

## 3. Paket & kuota (tugas 1.3)

- Harga 99k/199k/349k dan limit 50/150/300 **konsisten** di web, `PlanPricingService`, `SubscriptionService`, PRD, SERVICE. Harga add-on belum ditentukan (PRD: menyusul).
- **Kuota siswa tidak ditegakkan** → L1-A/1.7.
- **Entitlement landing page**: endpoint publik menolak (404) bila `!hasPublicWebsite()`, tetapi:
  - endpoint kelola `public-profile*` tidak mengecek paket (Starter bisa menulis data & upload via API);
  - `Akademi::hasPublicWebsite()` membaca snapshot `plan`, tidak memeriksa langganan aktif/kedaluwarsa.

## 4. Rute frontend (tugas 1.4)

- `academy/*` (akademi) dan `internal/*` (super admin) adalah dua pohon **berbeda** dan sah. `admin/*` hanya 21 stub redirect legacy; tidak ada link internal ke sana.
- `proxy.ts` me-rewrite `admin.<domain>/x` → `/admin/x`; stub lalu redirect ke `/internal` → di-rewrite lagi menjadi `/admin/internal` (404); `/login` berpotensi loop. **Perlu verifikasi di browser.**
- Tidak ada guard yang membatasi `/internal` hanya di subdomain admin (bukan celah keamanan — API tetap menegakkan role).
