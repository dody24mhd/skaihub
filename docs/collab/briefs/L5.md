## L5-A — E2E integrasi (dijalankan terakhir, setelah Fase 4 di-merge)
- Folder `dojang-hub-web/e2e-integration/` + `playwright.integration.config.ts` + script `npm run test:integration`. `webServer` ganda: API = `php artisan serve --port=8010` dengan env `DB_CONNECTION=sqlite DB_DATABASE=<path absolut file sqlite sementara di storage/testing/>` yang di-`migrate:fresh --seed` **hanya pada file sqlite itu** sebelum test; web = build production dengan `NEXT_PUBLIC_API_URL=http://127.0.0.1:8010/api`, port 3910. CORS harus mengizinkan origin itu (lewat env, bukan ubah default).
- Skenario (project mobile 375 + desktop 1280): login tiap role demo & menu sesuai role; ketua tambah siswa; pelatih buka "Kelas Hari Ini" → isi absensi (termasuk Sakit) → selesai; admin generate SPP → bayar parsial → lunas → lihat kwitansi; admin buat UKT → peserta lulus → sabuk siswa & riwayat berubah; landing page publik tampil untuk akademi Pro; pelatih tidak bisa membuka `/academy/spp` (ditolak/redirect).
- Bug integrasi yang ditemukan: perbaiki bila kecil & jelas (catat file & alasan), atau dokumentasikan di laporan bila besar.

## L5-B — Akun platform & ganti password
- Backend: `GET|POST|PUT|DELETE /super-admin/platform-users` — hanya super_admin; mengelola user `role=admin` (staf platform) tanpa `akademi_id`; tidak bisa mengubah/menonaktifkan diri sendiri; nonaktif → cabut token. `PUT /auth/password` `{ current_password, password, password_confirmation }` (min 8, `Password::defaults()`), semua role; sukses → cabut **token lain** (sesi saat ini tetap). Rate limit `throttle:6,1`.
- Frontend: ganti placeholder `src/app/(admin)/internal/users` dengan manager staf platform (`ResponsiveList` + `SheetModal`). Halaman "Ganti Password" untuk akademi (`/academy/account`) dan internal (`/internal/account`), ditautkan dari menu profil/Lainnya.
- Test: hak akses, self-protection, token revocation, validasi password lama salah → 422.

## L5-C — Rapor & sertifikat
- Backend: `GET /akademi/students/{student}/report?period_id=` → data rapor (identitas, kelas, sabuk, kehadiran periode, nilai per aspek + predikat + rata-rata, catatan pelatih) — Ketua/Admin/Pelatih, tenant-scoped. `GET /akademi/rank-promotions/{event}/participants/{participant}/certificate` → data sertifikat (hanya peserta `passed`).
- Frontend: halaman cetak `/academy/students/[id]/report` dan `/academy/rank-promotions/[eventId]/certificates/[participantId]` dengan desain sesuai DESIGN.md, `@media print` A4 (rapor portrait, sertifikat landscape), tombol "Cetak / Simpan PDF" (`window.print()`), tanpa dependensi PDF baru. Tautan dari detail siswa (pilih periode) dan dari daftar peserta UKT yang lulus.
- Test: tenant isolation, pelatih boleh rapor, sertifikat ditolak untuk peserta tidak lulus, unit test komponen cetak.

## L5-D — Ops & polish
- `sanitize-html.ts`: izinkan atribut `class` **hanya** dengan nilai berawalan `ql-` (perataan/indent Quill) dan tag `h1`; test bahwa `class="ql-align-center"` bertahan dan class lain dibuang.
- API `GET /api/health` (tanpa auth) → `{ status: "ok", db: true|false, time }` dengan cek koneksi DB ringan; dikecualikan dari rate limit ketat.
